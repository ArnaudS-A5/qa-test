overlay — clic intercepté par une surcouche

Le bouton #target est visible et enabled, mais un #overlay en position:fixed le recouvre entièrement (z-index supérieur).

Ce qu'on attend : un clic qui n'atteint jamais la cible — le hit-test JS du socle détecte l'interception (pas d'attente temporelle, état figé au chargement).

T9 : le diagnostic au timeout doit contenir le code [INTERCEPTED].
